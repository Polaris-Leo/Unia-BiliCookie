API 接口

GET /api/accounts/cookie

获取一个当前有效的 Cookie（自动轮换，外部服务集成入口）

响应示例 
{ "success": true, "data": { "uid": "123456", "username": "用户名", "cookies": { "SESSDATA": "...", "bili_jct": "...", ... } } }
GET /api/accounts

获取所有账号列表（不含 Cookie 值）

POST /api/accounts/validate-all

触发所有账号 Cookie 验证，返回验证汇总

GET /api/accounts/:uid/cookie

获取指定账号的 Cookie（含 Cookie 值）

POST /api/accounts/:uid/validate

验证单个账号 Cookie 有效性

DELETE /api/accounts/:uid

删除指定账号

与 Unia-Danmuku 集成

在 Unia-Danmuku 中，可以在需要获取 Cookie 时调用本服务的接口，实现多账号自动故障转移。当当前 Cookie 失效时，本服务会自动返回下一个有效账号的 Cookie。

curl 示例 
curl http://localhost:3100/api/accounts/cookie
